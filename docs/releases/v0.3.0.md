## Manual acceptance checklist

- [ ] Upload a PDF in the dashboard; a new `DocumentVersion` is created and the document appears in the list.
- [ ] Open a share link in an incognito window; the public viewer loads the PDF.
- [ ] Open the **AI Assistant** panel (bottom-right floating button), ask a question, and receive an answer with page-number citation badges.
- [ ] Click a citation badge; the viewer scrolls to that page and highlights it briefly.
- [ ] Ask a follow-up question in the same panel; conversation history is retained.
- [ ] Workspace admin sets AI provider to **BYOK** with an OpenAI key; document chat uses that key.
- [ ] Workspace admin sets AI provider to **Local** (Ollama); document chat uses the local endpoint.
- [ ] After more than 200 AI questions in one hour from the same workspace, the chat route returns `429`.
- [ ] `lib/audit.ts` logs contain `ai.query` events for every question.
- [ ] `/dashboard/settings/ai` loads and saves workspace AI configuration.
